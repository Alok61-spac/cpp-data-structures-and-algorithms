## Topic-Conditional statement



#### definattion-

Conditional statment are used to make decisions in a program. They allow the program to execute different blocks of code depending on whether a condition is true or false.



#### Conditional Statements-

##### 1\. if Statement



Executes a block of code only if the condition is true.



Syntax:



if (condition) {

&#x20;   // code

}



###### Example:



int age = 18;



if (age >= 18) {

&#x20;   cout << "Eligible to vote";

}

##### 2\. else Statement-



Executes one block if the condition is true and another if it is false.



Example:



int num = 5;



if (num % 2 == 0) {

&#x20;   cout << "Even";

} else {

&#x20;   cout << "Odd";

}

3\. else if Ladder



Used to check multiple conditions.



###### Example:



int marks = 85;



if (marks >= 90) {

&#x20;   cout << "Grade A";

} else if (marks >= 75) {

&#x20;   cout << "Grade B";

} else {

&#x20;   cout << "Grade C";

}
